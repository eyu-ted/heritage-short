# Heritage Short: "Buna"

A 60-90 second film about the Ethiopian coffee ceremony, narrated in Amharic with English subtitles and an original score, generated by a small code pipeline driven by one file: `storyboard.json`.

> Status: work in progress. See `PLAN.md` (design) and `IMPLEMENTATION.md` (steps).

## Run it (will be finalised in Phase 9)

```
python -m pipeline all      # or: make film
```

## Setup

1. Python 3.12 and FFmpeg (with libass) installed.
2. `python -m venv .venv` then activate it, then `pip install -r requirements.txt`.
3. Copy `.env.example` to `.env` and add your own keys. Never commit `.env`.
